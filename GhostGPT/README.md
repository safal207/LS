### 📁 СТРУКТУРА ПРОЕКТА:

```

```

### 🔧 НАСТРОЙКА:

1. **Получи Groq API ключ:** https://console.groq.com/keys
2. **Вставь в `config.py`:** `GROQ_API_KEY = "gsk_..."` 
3. **Установи VB-Cable:** Для захвата системного аудио
4. **Настрой аудио:** Вывод звука → CABLE Input

### 🚀 ЗАПУСК:

```bash
# Удобный запуск
run_ghostgpt.bat

# Или вручную
python main.py
```
