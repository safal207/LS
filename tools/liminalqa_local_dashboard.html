LiminalQA
Локальная панель

Маленькая локальная панель для пути LS -> LiminalQA и council-ledger analytics. Проверяй здоровье, публикуй quality snapshot и смотри вклад моделей по циклам согласования.

Smoke Publish
Отправляет один synthetic run с одним тестом и одним сигналом через /ingest/batch.
Local Test Lane
Локально запускает mesh-tests через pytest, пишет JUnit и coverage, потом пересчитывает quality report.
Quality Report
Сначала сгенерируй локальный artifacts/quality-report.json, потом публикуй его в LiminalQA как настоящий quality snapshot.
Query Preview
Отправляет маленький payload в /query и показывает последние факты, которые видит ingest service.
Quality Preview
Краткая сводка по текущему локальному quality report.
