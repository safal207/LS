# LS response validation input for PR #824

This directory is reserved for a real LS audit response for case `pr824-ls-audit-v0.1`.

## Important boundary

Do **not** commit a fabricated `ls_response.json`.

The default validation workflow expects the real response at:

```text
audits/ls-responses/pr824/ls_response.json
```

That file should be created only after an actual LS run has reviewed the audit pack generated by the `LS audit pack` workflow.

## Expected shape

Use `ls_response.example.json` only as a format guide. Copy it to `ls_response.json` and replace every value with the real LS run output.

## Validation

After committing the real `ls_response.json`, run:

```text
Actions -> LS response validation -> Run workflow
```

Use the default inputs:

```text
response_path: audits/ls-responses/pr824/ls_response.json
pr_number: 824
commit_sha: f1cfdfbf5f648bc28434fb2f5a0cb77eb7e86666
case_id: pr824-ls-audit-v0.1
```

The workflow will fail closed if the JSON is missing or invalid, and it will upload validation artifacts plus `comparison_scorecard.json`.
