## Claim boundary

Do not use About text that claims:

```text
formal Nash equilibrium;
global model ranking;
global contributor ranking;
statistical sufficiency;
production-grade governance;
that one route generalizes to all PR reviews.
```

Safe claim:

```text
LS exposes small, inspectable evidence paths for cooperative AI route evaluation.
```

## Manual GitHub UI steps

1. Open the LS repository on GitHub.
2. Click the gear icon near the About box.
3. Paste the recommended description.
4. Add the website URL.
5. Add the recommended topics.
6. Save changes.

## Done criteria

- About description is short and clear.
- Website points to GitHub Pages.
- Topics include AI agents, evaluation, local-first, code-review, and reproducibility.
- No overstated claims are present.
