# AI Co-work Continuity Outreach Kit

## Purpose

This kit provides ready-to-send outreach messages for LS as a session continuity and repair layer for AI co-work.

It supports the first practical offer:

- `docs/offers/AI_COWORK_CONTINUITY_AUDIT.md`

Core line:

```text
AI agents are becoming co-workers.
Co-work breaks when context breaks.
LS repairs the shared point before work continues.
```

## Use this when

You are contacting:

- DevTools / coding-agent teams;
- AI safety / governance grant reviewers;
- Security / GRC / RegTech teams;
- AI-heavy engineering teams;
- model labs / agent platform teams;
- AI infrastructure investors.

## Rules

```text
Lead with a narrow pain.
Do not lead with the entire ecosystem.
Offer a small audit, not a huge platform.
Show artifacts, not only claims.
Avoid employee-surveillance language.
Avoid claiming hallucinations are solved.
```

```text
AI agents are becoming co-workers, but co-work breaks when context breaks.

A coding agent may continue from a missing PR, stale branch, or assumed review outcome and produce a plausible but wrong next step.

The first offer is a 2-week AI Co-work Continuity Audit: we review 20-50 sessions or handoffs, classify where continuity breaks, and return repair prompts plus a gateway contract.
```

## Red-line wording to avoid

Do not write:

```text
LS knows the user's real intent.
```

Prefer:

```text
LS proposes and records testable hypotheses about intent, context, and continuity.
```

Do not write:

```text
LS eliminates hallucinations.
```

Prefer:

```text
LS detects conditions where hallucinated continuation is likely and forces repair before continuation.
```

Do not write:

```text
LS measures employee performance.
```

Prefer:

```text
LS supports human-owned growth signals and aggregate-safe team learning without exposing private cognitive graphs.
```

Do not write:

```text
LS is a compliance-certified security product.
```

Prefer:

```text
LS is an early open-source runtime and audit artifact layer for continuity, evidence, and governance.
```
