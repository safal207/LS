# LS Agent Shell Operator Delta

This page documents the investor-facing and legal-facing value of the new
`LS Agent Shell + LTP` operator loop.

It is based on a measured local snapshot generated by:

```bash
python -m ls.agent_shell.benchmarks.operator_delta
```

Source snapshot:

- `ghostgpt-ls-landing/src/data/operatorDeltaBenchmark.json`

Generated on:

- `2026-04-06T14:08:25Z`
- Windows / Python `3.11.9`
- queue size: `5` waiting approvals

## With LS + LTP

- one queue-wide replayable review path for waiting approvals
- batch triage before `approve`
- approval events stay attached to task and step
- replayable task traces can be reviewed again outside the original run

## Without This Layer

- operator hops across tasks one by one
- review context is split across multiple commands and handoffs
- no single batch replay path for the approval queue

## Measured Snapshot

| Scenario | Time | Commands | Notes |
| --- | ---: | ---: | --- |
| Manual CLI review | `15.48s` | `11` | `list` + `inspect` + `approvals` for each task |
| Per-task LTP review | `40.26s` | `5` | one `ltp-inspect` per task |
| Batch LTP review | `32.97s` | `1` | one `ltp-inspect-all` over the full queue |

Derived deltas:

- `7.29s` saved versus per-task `ltp-inspect`
- `18.11%` faster than per-task `ltp-inspect`
- `90.91%` command reduction versus manual queue review (`11 -> 1`)

## Why This Matters To Investors

- less operator overhead per approval queue
- clearer evidence that the product is not just generating outputs, but creating inspectable decision paths
- easier story for enterprise workflows where review cost and approval latency matter

## Why This Matters To Legal And Audit Teams

- replayable traces create a stable evidence layer
- approval history is preserved per task and per step
- batch review makes first-pass legal/risk triage faster before approval

This is not legal advice and not a universal benchmark claim. It is a local,
reproducible snapshot that demonstrates operator-loop compression and stronger
auditability on one development machine.
