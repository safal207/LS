# Ecosystem Reviewer Index

This page is a top-level reviewer index for LS / Liminal Stack and related repositories.

LS is the broad reviewer and governance surface. It connects local-first coordination, human-owned cognitive artifacts, session continuity, safety gates, cognitive trail contracts, and oversight workflows.

The related repositories are not exact aliases. They are different surfaces of one broader research program:

```text
make human-plus-agent systems inspectable,
causally grounded,
continuity-aware,
and reviewable before durable memory or high-risk action.
```

## Repository roles

| Repository / surface | Role in the ecosystem | Reviewer value |
| --- | --- | --- |
| LS / Liminal Stack | Broad governance, coordination, continuity, cognitive-trail, and reviewer narrative surface. | Shows the human-owned operating layer, grant-level framing, and a machine-validated trail contract. |
| Cognitive Trail Contract | LS-local contract for recording one measurable cooperative route. | Gives schema, examples, generated sample, validator, generator, CI, and reviewer quickstart. |
| ProofPath | Current executable implementation hub for action-boundary verification. | Gives runnable gateway, verifier, demos, audit logs, and reviewer paths. |
| Compute Witness | ProofPath workstream for reviewable AI/agent compute evidence. | Gives manifests, receipts, audit fixtures, Rust verifier path, and CI checks. |
| PythiaLabs | Evidence-gate project surface for high-risk agentic actions. | Shows the deterministic evidence-gate framing behind action review. |
| CML / Causal Memory Layer | Causal-validity and authorization-lineage layer. | Answers why an action was allowed and whether the causal chain is valid. |
| LTP / L-THREAD | Trace, replay, continuity, and admissibility-inspection layer. | Shows deterministic replay and trace inspection for agent execution paths. |

## How to read the ecosystem

### LS asks

```text
Can agent output become durable memory, profile state, coordination artifact, or action under human-owned governance?
```

### Cognitive Trail Contract asks

```text
Can we record and validate which cooperative route made one concrete task more precise?
```

### ProofPath asks

```text
Should this authenticated request become an executed high-risk action?
```

### Compute Witness asks

```text
Can this AI/agent compute result be trusted as reviewable evidence?
```

### PythiaLabs asks

```text
Should a high-risk agentic action pass through an evidence gate before tools are called?
```

### CML asks

```text
Why was this action allowed, and is the permission lineage causally valid?
```

### LTP asks

```text
Can we replay and inspect the execution path that produced this output, action, memory, or continuity event?
```

Together, the layers form a reviewer-visible path:

```text
coordination and continuity
  -> measurable cooperative route artifacts
  -> causal validity
  -> trace/replay inspection
  -> evidence gate
  -> executable action boundary
  -> reviewable compute evidence
```

## What this index does not claim

This page does not claim that all repositories are the same product or that every layer is production-ready.

It also does not claim:

- certified regulatory compliance;
- production key management;
- GPU hardware identity;
- trusted execution environment attestation;
- zkML correctness;
- model truthfulness;
- universal agent alignment;
- full cross-repository replay or dispute resolution;
- global ranking of models, tools, or human contributors;
- that LS already runs a global live Cognitive Trail Network.

The current claim is narrower:

```text
The ecosystem already contains connected, public, inspectable artifacts for reviewing human-plus-agent coordination, measurable cooperative routes, causal validity, trace continuity, evidence gates, and action boundaries.
```
