## Boundary

Keep the claim narrow:

```text
LS is an early open-source project for cooperative AI route evaluation and reviewer-visible evidence chains.
```

Do not claim:

```text
formal Nash equilibrium;
global model ranking;
global contributor ranking;
statistical sufficiency;
production-grade governance;
that one route generalizes to all PR reviews.
```
