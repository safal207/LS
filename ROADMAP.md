# Grant and Foundation Roadmap

This roadmap is focused on grant readiness and evidence production.

## Q2 2026

- Publish core governance and security documents.
- Stabilize CI around required security and quality gates.
- Define baseline values for impact KPIs.

## Q3 2026

- Deliver reproducible "10-minute demo" path.
- Publish first case studies with before/after metrics.
- Improve vulnerability remediation lead time and reporting.

## Q4 2026

- Expand external pilot/adopter evidence.
- Publish quarterly evidence report with KPI trendline.
- Prepare follow-on grant package with validated outcomes.

## Q1 2027

- Scale documentation and onboarding for external contributors.
- Institutionalize release operations and reliability SLOs.
- Update funding thesis based on measured outcomes.

## Dependencies

- Stable CI infrastructure and branch protections.
- Maintained changelog and release notes.
- Sustained data collection for KPI reporting.
