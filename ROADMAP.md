# LS Public Roadmap

LS is moving toward a personal control layer for multi-agent AI work: one memory, one quality gate, and one human approval path across many agents.

Live landing page: https://safal207.github.io/LS/

## Now

- Make the landing page clear for first-time visitors and investors.
- Keep GitHub Pages deployment green from `ghostgpt-ls-landing`.
- Turn the reflection panel into a small, believable demo of agent review before delivery.
- Collect community feedback on wording, diagrams, and onboarding.

## Next

- Add a short demo video or animated walkthrough to the landing page.
- Publish a minimal "agent output before LS / after LS" example.
- Add more replayable examples under `examples/` or `benchmark/`.
- Improve local setup docs for contributors who only want to run the landing page.
- Add screenshots to issues that are ready for design help.

## Later

- Connect the landing page to live, sanitized runtime snapshots.
- Split the product story into separate pages for safety, personal AI layer, and developer integration.
- Publish small public datasets of review traces where privacy permits.
- Add integrations for external agent tools through a documented gateway.

## Community Tasks

Good first areas:

- Landing copy: make complex LS ideas understandable in plain language.
- UI clarity: improve diagrams, button labels, and mobile layout.
- Docs: shorten setup paths and add examples.
- Tests: add focused checks for landing build, runtime fallback, and gateway contracts.
- Examples: create realistic before/after agent-output cases.

If you want to help, start with an issue labeled `good first issue`, `landing`, `docs`, or `demo`.
